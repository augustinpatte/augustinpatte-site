# Augustin Patte portfolio

Buildless static website, in English and French. Source content is in `scripts/content.mjs`; `scripts/generate.mjs` generates 17 routes in each language, plus the retained `/resume.html` route. The shared CSS and progressively enhanced JavaScript are in `dist/`.

Run `node scripts/generate.mjs` after editing content. Run `python scripts/check_site.py` to check all local routes, assets, fragment links, headings and image descriptions. Run `node --check dist/app.js` for JavaScript syntax. No runtime dependencies, external fonts, trackers, accounts or contact-form service are used.

The site preserves its existing owner-private access. `augustinpatte.com` has a pending native domain association; registration and DNS activation are separate and have not been completed. The canonical origin remains the verified Sites origin.

The home page ends with the user's Connect Four fun fact and a bilingual game. `scripts/game-template.mjs` renders its markup; `dist/connect-four.css`, `dist/connect-four.js` and the engine/worker scripts provide the game. All gameplay is local: no API, backend, accounts, analytics or external runtime dependencies. Easy plays simple tactics with a deliberately fallible defense; Medium searches up to 4 plies; Very hard uses iterative deepening up to 18 plies with a 2.2-second budget, tactical win/block detection, alpha-beta pruning and a transposition table. A Web Worker keeps calculation off the UI thread; a cooperative asynchronous fallback supports environments without workers. Difficulty/starting-player changes reset the board, and resets cancel old searches. `node scripts/check-connect-four.mjs` checks tactical play, draw/full-column handling, cancellation and fallback responsiveness. The engine is deliberately not advertised as unbeatable.
