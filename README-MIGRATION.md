# Augustin Patte — site source

This folder contains the full source code and the generated static website.

## Publish without the ChatGPT Sites address

Use a static host such as Cloudflare Pages, Vercel or GitHub Pages. Set the published directory to `dist`.

For Cloudflare Pages:

1. Create a new Pages project from this code in a private GitHub repository.
2. Set the build command to `node scripts/generate.mjs`.
3. Set the build output directory to `dist`.
4. Add `augustinpatte.com` as the custom domain in Cloudflare Pages.
5. In Cloudflare DNS, point the domain to the Pages project as instructed by Cloudflare.
6. Confirm that `https://augustinpatte.com` works before taking the former hosted version offline.

The canonical URLs, alternate-language URLs and sitemap are already set to `https://augustinpatte.com`.

## Local update

Edit the source modules in `scripts/`, then regenerate the static files:

```bash
node scripts/generate.mjs
python scripts/check_site.py
```

The deployable website is the `dist/` directory. Do not edit its HTML directly: it is generated by `scripts/generate.mjs`.
